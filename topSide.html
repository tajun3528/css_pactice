What is the cascade?

The rules the browser uses to pick a winner when several declarations target the same element: origin, layer, specificity, then source order.

Why use clamp()?

It sets a minimum, a flexible preferred size and a maximum in one value, so type and spacing scale smoothly.

When should I use grid or flexbox?

Use flexbox for one-dimensional rows or columns. Use grid when you need control over rows and columns together.
